# MacLaunch

CLaunchの主な操作を参考に、Swift / AppKitで独自実装したmacOS用のボタン型ランチャーです。外部ライブラリや開発サーバーを必要とせず動作します。URLを開くときは既定のブラウザを使用します。

**CLaunch公式のmacOS版ではありません。CLaunchの作者による提供・公認を示すものではありません。**

参考元：[CLaunch（作者：ぴょんきち氏）](https://ss1.xrea.com/pyonkichi.g1.xrea.com/claunch.html)。CLaunch本体・ソースコード・配布スキンの画像やXMLは、このリポジトリとアプリには同梱していません。スキンの構成や公開仕様を参考に、描画とアプリアイコンを本プロジェクトのコードで作成しています。登録先アプリのアイコンは実行時にmacOSから取得します。

## 起動

ビルド後の `dist/MacLaunch.app` を `~/Applications` または `/Applications` にコピーし、ダブルクリックしてください。メニューバーの「4つの四角」に常駐します。Dockには表示されません。

ログイン時の自動起動は、macOSの「システム設定 → 一般 → ログイン項目と機能拡張 → ログイン時に開く」から、配置したMacLaunch.appを追加してください。

ソースはmacOS 13以降に対応します。ビルドしたMacのアーキテクチャ向けのアプリが生成されます。Intel Macでは対象のMac上でビルドしてください。

## 基本操作

| 操作 | 動作 |
| --- | --- |
| 設定した呼び出しキー（初期値 ⌘⇧Space） | ランチャーを表示／非表示 |
| メニューバーの四角をクリック | 表示／非表示 |
| メニューバーの四角を右クリック | 設定メニュー |
| アイコンをクリック | アプリ・ファイル・フォルダ・URLを開く |
| Finderからドロップ | アイテムを登録（複数選択対応） |
| アイコンをドラッグ | 空きマスへ移動。登録済みボタンへはその直前に挿入。Optionを押しながらでコピー |
| アイコンを右クリック | プロパティ・空白挿入・Finder表示・別ページへ移動・登録解除 |
| 空きボタンをダブルクリック / 上部の＋ / ⌘N | 新しい登録画面を開く |
| 空きボタンを右クリック | 登録画面・直接ファイル選択・起動中アプリ・よく使うフォルダ・URL・クリップボードから登録 |
| タブを右クリック | ページ名変更・並べ替え・削除 |
| タブ右端の＋ | ページ追加 |
| ホイール | ページ切替。縦に項目があふれる場合はスクロール。タブの上では常にページ切替 |
| ⌘1〜9 | 指定ページへ移動 |
| ⌘← / ⌘→ | 前／次のページ |
| ⌘F | すべてのページから検索 |
| ⌘N | アイテム登録 |
| 矢印キー / Return | アイコン選択 / 起動 |
| Esc | 検索をクリア。検索が空なら非表示 |
| 左上の鍵 | ウィンドウロック（表示を固定）／解除 |

通常は、カーソルがウインドウから離れると約0.55秒後に隠れます。キーボードで呼び出してカーソルをまだウインドウに入れていない場合は、そのまま操作できます。別アプリをクリックすると隠れます。左上の鍵でウィンドウロックすると表示を維持します。

設定メニューから「画面の隅から呼び出す」を有効にできます。選んだ隅に約0.25秒カーソルを置くと表示します。macOSのホットコーナーと重なる場合は別の隅を選んでください。

## 1.2の画面と登録方法

CLaunchのFluent Lightスキンを参考に、28pxの上枠、7列×3行、58pxのボタンと32pxのアイコンを基本にしました。大きな検索欄は通常時は隠れ、虫眼鏡または⌘Fで表示します。

設定 → **スキン** で Fluent Light / Solid Dark / Glass Blue を切り替えられます。**表示・ボタン配置** ではタブの上下、5・7・9列、3・6行、アイコン名の有無を設定できます。上部の格子ボタンでも3行／6行を切り替えられます。

**空きボタンをダブルクリック**すると、登録画面が開きます。

- **アプリ**：アプリ名で検索して選択。「起動中」からも選べます。⌘クリック・Shiftクリックで複数選択できます。
- **ファイル・フォルダ**：ドロップ、ファイル選択、フォルダ選択、よく使うフォルダの一覧から指定できます。
- **URL**：ブラウザからドロップ、直接入力、クリップボードから入力できます。登録名を省略すると自動で名前を付けます。
- **登録後も開いたままにする**：続けて別のアイテムを登録できます。

空きボタンへ直接ドロップすれば、登録画面を開かずにそのマスへ登録できます。複数ファイルは、その位置から空いているマスに順番に入り、登録済みアイコンを上書きしません。同じページの登録済みアイテムは重複追加しません。空きボタンを選択して⌘Vでも登録できます。

アイコンを移動すると移動元は空白になります。タブの上にドラッグして約0.4秒待つとページが切り替わり、別のページへ移動できます。Optionを押しながらドラッグするとコピーになります。画面隅からの呼び出しを有効にしていれば、外部ファイルのドラッグ中も呼び出せます。

## 呼び出しキーを自由に設定する

1. ランチャー右上の歯車のアイコン、またはメニューバーの四角を右クリックして設定を開きます。
2. **呼び出しキー → ショートカットを変更…** を選びます。
3. 入力欄をクリックして、使いたいキーの組み合わせ（例：Control＋Option＋L）を実際に押します。
4. 表示された組み合わせを確認して **保存** を押します。次の起動後も設定を維持します。

Command（⌘）・Control（⌃）・Option（⌥）のいずれかと、文字・数字・Space・矢印などのキーを組み合わせられます。Shift（⇧）も追加できます。F1〜F20は単独でも登録できます。修飾キーだけ、文字キー単独、Shift＋文字だけの指定はできません。Fn／地球儀キーだけの指定には対応していません。

**初期設定に戻す → 保存** で ⌘⇧Space に戻せます。**キャンセル** では設定を変更しません。入力中のEscは記録をやめ、もう一度Escを押すとキャンセルします。以前の3つの候補もメニューに残しています。

macOSの有効なシステムショートカットと重複すると、入力時または保存時にエラーを表示します。登録や保存が失敗した場合は元の呼び出しキーを維持します。macOSが先に処理する組み合わせは入力欄で記録できない場合があります。他アプリが独自に処理するキーとの重複はすべて検出できるわけではないため、普段使うショートカットと重ならない組み合わせを選んでください。

この画面で変えられるのはランチャーを呼び出すキーです。⌘F・⌘Nなどのランチャー内の操作キーや、アイテムごとの起動キーのカスタマイズは含みません。

## 保存・バックアップ

登録内容と設定は `~/Library/Application Support/MacLaunch/library.json` に自動保存します。

- 設定 → **設定を書き出す**：JSONファイルとして保存
- 設定 → **設定を読み込む**：内容を確認して置換。置換前の設定は同じフォルダに自動バックアップ
- 設定 → **設定フォルダを開く**：保存先をFinderで表示

登録解除はショートカットの解除です。元のアプリやファイルは削除しません。ファイルを移動した場合は、アイコンを右クリックして「プロパティ」からパスを変更してください。

## ビルド・テスト

XcodeまたはSwiftの開発ツールをインストールしたMacで実行します。依存パッケージのダウンロードはありません。

```sh
git clone https://github.com/mochimido/MacLaunch.git
cd MacLaunch
swift test
bash scripts/build.sh
```

生成物は `dist/MacLaunch.app` です。ビルドスクリプトはこのMacで実行するためのアドホック署名を付けます。ほかのMacへ配布するためのDeveloper ID署名・公証は含みません。

## 現在の範囲

これはCLaunchの全機能を移植したものではなく、独立した最初の実装です。ボタン型表示、ページ、ホットキー、画面隅からの呼び出し、自動非表示、検索、登録・編集、並べ替え、JSON保存に対応しています。

CLaunch独自のスキン／設定ファイルの互換性、マウスジェスチャー、デスクトップのダブルクリックによる呼び出し、サブメニュー、アイテムごとのホットキー、コマンド引数指定は未実装です。ログイン時の自動起動が必要な場合は、macOSの「システム設定 → 一般 → ログイン項目」にアプリを追加してください。

## 検証

設定の保存・再読込、失敗時の状態維持、設定破損の保持、読込前のバックアップ、ページ削除後の選択状態、同一ページ／ページ間の並べ替え、入力検証を自動テストで確認しています。

自動テストは18件。実画面ではライト／ダーク／グラスの切替、タブ下配置、表示行数切替、起動中アプリの複数選択と連続登録、URL補完、よく使うフォルダの入力を確認しています。以前の起動・検索・ページ編集・設定読込・ショートカット設定の検証も維持しています。ドラッグ操作は確認用UIツールが未対応のため、並べ替え処理を自動テストで検証しています。
